# Security Policy

## Reporting a Vulnerability

Please report security issues privately to project maintainers before opening a
public issue.

Include:

1. Affected component and version/commit.
2. Reproduction steps or proof of concept.
3. Impact assessment.
4. Suggested mitigation if available.

## Response Targets

1. Initial acknowledgment: within 7 days.
2. Triage decision: within 14 days.
3. Fix timeline: depends on severity and release schedule.
