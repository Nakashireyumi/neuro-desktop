# Development review — 2026-10-23

Reviewed the development history from `122fb48` through `a94b0c7`, the open PRs,
branch rules, catalog snapshot, independent SDK/adapter revisions, and CI results.
The source move, action/context changes, desktop capability reporting, Vision
limits, devcontainer, module guide, packaging paths and branding were the main
areas examined. This is a development review, not installed-release acceptance.

## Corrections

- **Product and language names:** Neuro Desktop remains the product. Neurcro is
  its macro language. The native manager, browser UI, bundles, API display names,
  docs, catalog, SDK and Vencord adapter follow that distinction. Existing scripts,
  executable names and the `run_script` protocol remain compatible.
- **Queued game input:** movement, looking, actions and key presses retain the
  session that supplied their controls. Ending or replacing that session rejects
  the old batch before dispatch, including replacement with the same profile.
  Discarding an unstarted batch does not release a replacement session's input.
  Session generations are independent of timestamps: Windows CI demonstrated
  that separate starts can share a wall-clock tick.
- **Windows file IPC:** polling retries transient sharing/lock violations within
  the existing deadline. Atomic file replacement can briefly exclude readers;
  permission failures and invalid protocol files still fail immediately.
- **Vision deadlines:** an inactivity timeout did not bound a peer that kept
  sending bytes. Absolute socket deadlines now interrupt upstream headers/bodies
  and incoming headers/uploads. Expired uploads free their inference slot.
  Model and worker requests ignore ambient proxies and still refuse redirects.
- **Devcontainer help:** its GUI-test command now includes the manager import
  path, matching the actual test invocation.

The signed Memory catalog entry retains its original bytes. A presentation
transform already addresses the operator directly and explains delegated
management; changing its signed description needs the publisher's signature.

The previous candidate's upstream push run `39798161115` and PR run `39798168782`

HTTP request withholds the result but cannot guarantee cancellation of compute
